# SAWYAN (`سويا`) — V3.0 Global Investment Consumption Ecosystem

**منصة الاستهلاك الاستثماري العالمية (`Buy and Make Money`) — الإصدار المعماري V3.0**

## 🏗️ البنية المعمارية المزدوجة (`Single Codebase + Dual Environment — D10`)

يعمل النظام من قاعدة كود موحدة متطابقة (`100% SHA-256 Parity`) مع توجيه ديناميكي معزول تماماً في PostgreSQL 17.6:

| البيئة | المسار | مخطط قاعدة البيانات (`Schema`) | الوصف |
| :--- | :--- | :--- | :--- |
| **الموقع الأصلي الحي (Production)** | `/` | `sawyan` | بيئة الإنتاج الحقيقية، تبدأ بالجذر المؤسس للشركة (`#0`) فقط مع قفل صارم للصلاحيات (`RLS`). |
| **الموقع الموازي للتجربة (Parallel Sandbox)** | `/preview/` أو `?env=demo` | `sawyan_demo` | بيئة التدريب والاختبار المعزولة (شجرة تجريبية من `50` عضواً `28 يمين / 20 يسار`، تجار وكاشير وحسابات حوكمة مشفرة بـ Bcrypt). |

## 🛡️ الركائز الهندسية والرقابية المعتمدة (V3.0)

1. **43 جدولاً قياسياً محمياً بـ RLS (`100%`)** ودليل حسابات مزدوج من **22 حساباً (`Chart of Accounts`)** بقيد توازن صفري صارم (`SUM(Dr) = SUM(Cr)`).
2. **فصل صارم للأدوار الـ 7 (`RBAC`) والاعتماد المزدوج (`Maker != Checker`)** على مستوى PostgreSQL، مع قفل قراءة فقط (`Read-Only`) لدور المدقق المستقل (`auditor`).
3. **معالج الإقفال الشهري ذو الـ 6 خطوات**: المطابقة الصفرية ← المسح الصعودي الحتمي (`Bottom-Up DAG`) ← الهدف التعويضي (`D1`) ← قطع السنتات (`TRUNC` لحساب `4301`) ← إعادة تقييم العملات (`IAS 21`) وعزل الستوبر المالي (`S03 Pro-Rata`) ← القفل الصلب (`Hard Lock`) واستثناء `Break-Glass` الموثق.
4. **بوابة تفعيل الدول (`D13 / D18`) والمحاكي الأكتواري (`S06`)**: التحقق الرياضي المسبق من الملاءة الصفرية للعجز قبل تفعيل أي دولة جديدة.
5. **بوابة التحقق الآلي (`database/run_zero_defect_gate.py`)**: فحص آلي لتطابق العقود البرمجية (`41 RPCs`)، التطابق المزدوج (`SHA-256`)، وحظر أي كلمات مرور افتراضية أو تسريب مفاتيح.
