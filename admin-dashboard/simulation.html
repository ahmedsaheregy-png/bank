🌳 سيناريو الشجرة

المنطق المعتمد (مطابق للتوثيق):
• max_depth = N - 1 ثابت لكل الأعضاء (شامل العضو نفسه = N مستويات)
• share_per_member = min(members_share / N, cap)
• bottom_up = min(generation, N) × share_per — كل عضو يدفع لنفسه + الأبلاينز حتى الستوبر
• with_stopper = حجم الفريق محدود بـ N-1 × share_per
• no_stopper = حجم الفريق الكامل × share_per (شامل كل الفريق)
